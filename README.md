## IPFS Information

The collection artwork is stored on IPFS so it is not dependent on a single traditional web server.

**Image CID**

~~~text
QmYxLeAzjSbpFkjxUVwGofNMmXrBSS7B7HzWkrUmdEhYjY
~~~

**Canonical image format**

~~~text
ipfs://QmYxLeAzjSbpFkjxUVwGofNMmXrBSS7B7HzWkrUmdEhYjY/{token-id}.png
~~~

Example:

~~~text
ipfs://QmYxLeAzjSbpFkjxUVwGofNMmXrBSS7B7HzWkrUmdEhYjY/0.png
~~~

The website automatically attempts multiple public IPFS gateways when an image cannot be retrieved from the first gateway.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload **index.html** and **README.md** to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the **main** branch and **/root** folder.
7. Save the settings.

The published address will follow this format:

~~~text
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
~~~

## Running Locally

Download **index.html** and open it in a modern browser. An internet connection is required to retrieve the collection artwork from IPFS and display the external banner.
